Estructures avançades en Python

En Python, les dades es divideixen en mutables i immutables, depenent de si el seu contingut pot canviar després de la seua creació.

Els objectes immutables no poden canviar el seu contingut després de ser creats.
Qualsevol “modificació” realment crea un nou objecte en memòria.

En Python, els tipus de dades immutables:

  • Nombres (int, float, complex)
  • Cadenes de text (str)
  • Tuples (tuple)
  • Conjunts immutables (frozenset)
  • Booleans (bool)

Els objectes mutables poden canviar el seu contingut sense canviar la seua identitat en memòria.
Qualsevol “modificació” , manipula l'objecte en memòria, no crea nou.

En Python, els tipus de dades mutables:

  • Llistes (list)
  • Diccionaris (dict)
  • Conjunts (set)
  • Objectes definits per l'usuari (classes)

Objectes immutables (int, str, bool...)

a = 3    # Es crea el literal 3 en memòria i s'assigna el seu “identificador” a la variable a

Per “identificador” es fa referència a un identificador d'objecte (no a una adreça de memòria). Aquest identificador es pot obtindre amb la funció id(var).

Objectes mutables (llistes, diccionaris, conjunts, definits per l'usuari...)

En Python, les variables són referències a objectes en memòria, no contenidors de dades directament. Quan fas una assignació com:

a = [1, 2, 3]     # a és una llista, per tant mutable
b = a

Tant a com b apunten al mateix objecte (una llista en aquest cas). No es crea una còpia de la llista; simplement, ambdues variables fan referència al mateix objecte. Si modifiques la llista a través de b:

b.append(4)    # això afegeix un element al final de la llista

La llista a la qual a apunta també es veu modificada, ja que a i b fan referència al mateix objecte en memòria.

Referències i aliasing

La diferència amb els objectes immutables és que quan modifiquem un objecte mutable, no es crea un de nou (si no existeix), com passa amb els immutables. Es modifica l’objecte i es mantenen les referències.

Una altra diferència amb els immutables és que quan assignem una llista a una variable, ES CREA una nova llista (encara que ja n’existisca una amb els mateixos elements).

a = [1, 2, 3]

b = [1, 2, 3]

print(a is b)
False

print(a == b)
True

Això no pot passar amb els objectes immutables. En el cas de dos objectes immutables iguals, s’apunta al mateix.

Llistes []

Les llistes són estructures de dades que poden emmagatzemar diversos elements.

  • Són ordenades. Suporten indexació i slicing.
  • Són Mutables: Es poden modificar després de ser creades.
  • Es poden afegir o eliminar elements amb mètodes com append(), remove(), pop(), etc.
  • Els elements poden ser mutables o immutables.
  • Es poden niar. (un element de la llista, pot ser una altra llista)
Dir que les llistes de Python són ordenades significa que mantenen l'ordre d'inserció dels seus elements. (Una altra cosa és dir que els elements estan ordenats (segons algun criteri, com p.e. alfabeticament, o numericament...).
    Això implica
  1. Ordre d'Inserció Fixe: L'ordre en què afegiu els elements a una llista és l'ordre en què es guarden. Aquest ordre és estable i previsible i només canviarà si feu una operació específica per reordenar-la (com ara .sort() o .reverse()).
  2. Indexació: Podeu accedir a qualsevol element de la llista utilitzant el seu índex numèric (posició), començant per 0. Això és possible precisament perquè la posició de cada element no varia.
  3. Iteració Previsible: Quan recorreu la llista (amb un bucle for, per exemple), els elements sempre eixiran en la seqüència exacta en què varen ser introduïts

Python List comprehension o Comprensió de llistes en Python

La comprensió de llistes en Python és una manera concisa i eficient de crear llistes a partir d'iterables com llistes, tuples, rangs, etc.

Sintaxi bàsica:

  nova_llista = [expressio for element in iterable if condició]
      • expressio: operació o transformació aplicada a cada element
      • element: variable que pren els valors de l'iterable
      • iterable: objecte iterable (llista, tupla, rang, etc.)
      • if condició (opcional): filtra els elements

Exemples de comprensió de llistes

  1. Crear una llista de quadrats: 
      quadrats = [x**2 for x in range(10)]
  print(quadrats)  
  # Resultat: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
  2. Filtrar nombres parells: 
      parells = [x for x in range(10) if x % 2 == 0]
  print(parells)  
  # Resultat: [0, 2, 4, 6, 8]
  3. Convertir paraules a majúscules: 
      paraules = ["hola", "món", "python"]
  majuscules = [paraula.upper() for paraula in paraules]
  print(majuscules)  
  # Resultat: ['HOLA', 'MÓN', 'PYTHON']

Operacions agregades en Python

Operacions agregades i de tractament de col·leccions

Quan treballem amb una col·lecció de dades, com una llista de Python, normalment no volem treballar només amb un element. Sovint necessitem analitzar, buscar, ordenar, filtrar o transformar molts elements alhora.

Per exemple, imaginem que tenim les notes d'un grup d'alumnes:

notes = [7, 4, 9, 6, 4, 8, 5, 10, 3, 4]

Python ens proporciona diferents operacions per treballar amb aquesta col·lecció.

1. Agregar: obtenir informació resumida

Les operacions agregades recorren una col·lecció i obtenen un resultat que resumeix les dades.

print(sum(notes))  # sols si els elements son numeros
print(max(notes))       # els elements deuen ser comparables entre ells
print(min(notes))
print(len(notes))   #Quants elements té la llista

max, min, sum i len també es poden aplicar a tuples, sets i dicts

2. Buscar

Podem comprovar si un element existeix en una col·lecció: (amb in )

if 10 in notes:
    print("La nota 10 existeix")
else:
    print("La nota 10 NO existeix")

in també es pot aplicar a tuples, sets i dicts

També podem buscar un element concret: amb index(element)

posicio = notes.index(9)
print(posicio)

==> Important: si l'element no existeix, index() provoca un error ValueError:

==> Important: si l'element està més d'una vegada, index() tornarà la posició del primer element

I pot ser que un element estiga més d'una vegada en la llista, i per saber quantes vegades està (amb count(element) )...

quantitat = notes.count(4)   #  Quantes aparicions té l'element "4"
print(quantitat)

També es pot fer servir .index() amb un paràmetre que indique, a partir de quin element buscar..

posicio2 = notes.index(4,2)

3. Ordenar

Podem ordenar els elements (els elements han de ser comparables entre si) amb:

notes.sort()
print(notes)

Compte !! Esta funció modifica la llista

# També podem ordenar de major a menor:
notes.sort(reverse=True)

Si els elements d'una llista no son del mateix tipus, no es podran ordenar, i si s'intenta, donarà un Error => TypeError

Una altra possibilitat és fer servir la funció sorted(), que crea una nova llista ordenada:

notes_ordenades = sorted(notes)

Esta funció NO modifica la llista, la deixa intacta i crea una altra ordenada

Un tipus d'ordenació sense comparar elements és reverse()

# reverse() modifica la llista, posa l'ultim el primer, el penultim el segon, etc.....
llista1.reverse()

Igual que en sort(), en reverse() existeix en Python reversed(), però no torna una llista, torna un iterador, i no es modifica la llista original

4. Filtrar

Filtrar significa seleccionar només els elements que compleixen una determinada condició.

aprovats = [nota for nota in notes if nota >= 5]
print(aprovats)

5. Transformar

Transformar significa aplicar una operació a cada element per obtenir una nova col·lecció.

# Per exemple, podem augmentar totes les notes un punt:
noves_notes = [nota + 1 for nota in notes]
print(noves_notes)

6. Agrupar

Agrupar significa reunir elements segons alguna característica comuna.

    ("Anna", "DAW"),

DAW  → Anna, Pere

    if curs not in grups:

Tuples ()

Les tuples són com les llistes però, una vegada declarades, no es poden modificar (són immutables).

  • Són ordenades. Suporten indexació i slicing.
  • Són Immutables: No es poden modificar després de ser creades.
  • No Es poden afegir o eliminar elements.
  • Els elements poden ser mutables o immutables.(per exemple, una llista dins d’una tupla Sí que pot canviar).
  • Es poden niar.(una tupla pot contenir altres tuples).

Quan usar tuples en lloc de llistes?

  • Quan les dades no han de canviar (exemple: coordenades, dies de la setmana).
  • Quan es busca més eficiència (les tuples consumeixen menys memòria i són més ràpides).
  • Quan es necessiten dades hashables (les tuples es poden usar com a claus en diccionaris, les llistes no).

Tuple Comprehension?

En Python no existeix la "tuple comprehension" com a tal.

Si usem parèntesis (()) per intentar fer una comprensió, Python ho interpreta com un generator expression:

tupla = (x**2 for x in range(5))
print(tupla)
# Resultat: <generator object at 0x...>

Açò no crea una tupla, sinó un objecte generador. Per convertir-lo en tupla:

tupla = tuple(x**2 for x in range(5))
print(tupla)

Avantatges d’un generador:

  1. Eficiència de memòria: no carrega tots els elements a memòria.
  2. Rendiment: útil per a grans volums de dades.
  3. Simplicitat: codi més net que una funció generadora.

Conjunts -sets- {}

Característiques principals

  1. Elements únics: Un conjunt no pot contindre duplicats.
  2. No ordenats: Els elements no tenen un ordre específic.
  3. Mutables: Es poden afegir o eliminar elements.
  4. Els elements han de ser immutables: podem afegir o llevar, però no modificar un element concret.

Ordenats o No ordenats: en Python els conjunts (sets) no són ordenats. Això vol dir que els elements d'un conjunt no tenen una posició específica o un ordre fixe. Quan s'imprimeix un conjunt o s'itera sobre ell, l'ordre dels elements pot ser diferent del que es va utilitzar per crear-lo i, de fet, pot canviar entre diferents execucions del programa o amb el temps.

🔢 Què passa amb els Nombres?

Quan Python mostra un conjunt de nombres, pot semblar que està ordenat de vegades, però això és una coincidència a causa de com es calcula el hash i com s'organitzen els nombres a la memòria, no és una propietat garantida del tipus de dades set

Exemples d’ús

  conjunt_buit={}        # No es construeix així un conjunt. Açò crea un dict
  conjunt_buit = set()   # Així SI

  conjunt = set( (1, 2, 3, 3) ) # convertir una tupla en conjunt
  conjunt.add(4)               # afegir un element ( el nombre 4)
  conjunt.add( [5, 6])         # afegir UN element ( la llista [5, 6] ) ->  {1,2,3,4, [5,6] }
  conjunt.update([3,6,7,8])    # afegir elements d'una llista (u per u) 
                               #  ( el nombre 3 no s'afegix perque ja existeix en el conjunt)
  conjunt.remove(2)            # elimina el nombre 2, dona error si no existeix
  conjunt.discard(4)           # elimina el nombre 4, no dona error si no existeix
  conjunt.pop()                # elimina i retorna un element aleatori. Si c es buit dona Error
  conjunt.clear()              # buida el conjunt
  
  type(conjunt) is set         # comprova si és un conjunt (identitat)
  
  a = frozenset([1, 2, 3])     # conjunt immutable
  conjunt = {1, 2.5, "hola", (1, 2), frozenset([3, 4])}
  
  # Recorrer un conjunt
  for element in conjunt:

Diccionaris { , }

Els diccionaris emmagatzemen parells clau-valor.

Característiques principals

  1. Mutables
  2. No permeten claus duplicades. Si s’afegeix una clau repetida, el seu valor serà sobreescrit.
  3. Les claus han de ser immutables. Poden ser str, int, tuple, però no list o dict.
  4. Mantenen l’ordre d’inserció (des de Python 3.7).

Exemples d’ús

  dic = {}  # Diccionari buit
  persona = {"nom": "Carlos", "edat": 30, "ciutat": "Madrid"}
  print(persona["nom"])  # Accedeix al valor d’una clau. Imprimeix 'Carlos'
  
  dic["nova_clau"] = "nou_valor"      # Afegir una nova clau
  dic["clau1"] = "valor_actualitzat"  # Modificar el valor d'una clau existent
  valor = dic["clau1"]  # Accedir a un valor (error si no existeix)
  valor = dic.get("clau1", "per defecte")  # Evita errors si no existeix
  
  del dic["clau1"]  # Eliminar una clau
  valor = dic.pop("clau2", None)  # Elimina i retorna el valor, o None
  
  dic.clear()  # Buida el diccionari
  
  if "clau1" in dic:
      print("Clau trobada")
  
  # Iteracions
  for clau in dic:
      print(clau)
  
  for valor in dic.values():
      print(valor)
  
  for clau, valor in dic.items():
      print(clau, valor)
  
  tamany = len(dic)  # Nombre d’elements
  nou_dic = dic.copy()  # Còpia superficial
  dic.update({"clau3": "valor3", "clau4": "valor4"})  # Afegir/modificar diverses claus
  
  claus = dic.keys()     # objecte dict_keys
  valors = dic.values()  # objecte dict_values
  items = dic.items()    # objecte dict_items
  
  type(dic) is dict  # Comprova si és un diccionari

  dict.update(dict2)   # Fundeix dos diccionaris. Modifica dict. Retorna None
  d.update(y=2, z=3)  # Passant més d'un parell, com arguments
  d.update([("y", 2), ("z", 3)])  # Passant tuples, com arguments
  
  dic1 | dic2   # (Python 3.9+) Fundeix dos diccionaris. Prioritza dic2. Retorna diccionari. 
                # No modifica ni dict1 ni dict2

  dic1 |= dic2  # Fusiona i actualitza dic1. Equival a dic1 = dic1 | dic2

Funcions lambda (funcions anònimes)

Una expressió lambda en Python permet crear funcions petites i anònimes (sense nom). Són útils per definir comportaments ràpids o temporals, especialment dins d’estructures com diccionaris, funcions d’ordre superior (map, filter, sorted, etc.) o comprensions.

Ús de *args i **kwargs

*args permet passar un nombre variable d’arguments posicionals a una funció. S’emmagatzemen com una tupla.

def exemple(*args, **kwargs):

Funcions d'ordre superior - map, filter

Una funció d’ordre superior és una funció que: rep una funció com a argument, i/o retorna una funció. reduce també és d'ordre superior, pero no és built-in

map

Què és map: És una funció que servix per aplicar una (mateixa) operació a cada element d’un iterable (com una llista, tupla, etc.) i retornar els resultats.

map(funció, iterable)
valors = ["1", "2", "3"]
numeros = map(int, valors)   # La funció pot set també "user-defined"
print(numeros)
<map object at 0x00000198FA7D5F00> 
print(list(numeros))
[1, 2, 3]
    📌 Detalls importants
  • map no crea una llista directament, crea un iterador
  • cal usar list() si vols veure els valors

filter

filter és una funció que servix per seleccionar elements d’un iterable segons una condició. A diferència de map, que transforma valors, filter decideix quins es queden.

nums = [1, 2, 3, 4, 5, 6]
parells = filter(lambda x: x % 2 == 0, nums)
list(parells)

Com map, retorna un iterador, no una llista

Exemples de lambda amb funcions d’ordre superior

  # map
  numeros = [1, 2, 3, 4]
  dobles = list(map(lambda x: x * 2, numeros))
  
  # filter
  pares = list(filter(lambda x: x % 2 == 0, numeros))
  
  # sorted amb clau
  paraules = ["poma", "plàtan", "kiwi"]
  ordenades = sorted(paraules, key=lambda x: len(x))

Decoradors en Python

Un decorador és una funció que rep una altra funció, l’amplia amb funcionalitat addicional, i retorna una nova funció. 

  def mi_decorador(func):
      def nova_funcio():
          print("Abans de cridar la funció")
          func()
          print("Després de cridar la funció")
      return nova_funcio
  
  @mi_decorador
  def salutacio():
      print("Hola, món!")
  
  salutacio()

Decoradors amb paràmetres

  def decorador_amb_args(func):
      def embolcall(*args, **kwargs):
          print(f"Cridant {func.__name__} amb {args} {kwargs}")
          return func(*args, **kwargs)
      return embolcall
  
  @decorador_amb_args
  def suma(a, b):
      return a + b

Decorador amb paràmetres personalitzats

  def repetidor(n):
      def decorador(func):
          def embolcall(*args, **kwargs):
              for _ in range(n):
                  func(*args, **kwargs)
          return embolcall
      return decorador
  
  @repetidor(3)
  def hola():
      print("Hola!")
  
  hola()

Decoradors predefinits

  • @staticmethod: mètode estàtic d’una classe.
  • @classmethod: accedeix a la classe com a primer argument.
  • @property: converteix un mètode en propietat.
  class Persona:
      def __init__(self, nom):
          self._nom = nom
  
      @property
      def nom(self):
          return self._nom
  
  p = Persona("Carles")
  print(p.nom)  # Sense parèntesis

Generadors

Els generadors són una manera més senzilla i eficient de crear iterables en Python. S'utilitzen funcions amb la paraula clau yield en lloc de return.

Quan una funció conté yield, es converteix en un generador i pot conservar l'estat entre iteracions.

Exemple de generador:

def comptador(inici, fi):
  while inici <= fi:
      yield inici
      inici += 1

for numero in comptador(1, 5):
  print(numero)

Este codi té el mateix comportament que la classe Comptador de l'exemple anterior, però és molt més curt i fàcil de llegir.

Avantatges dels generadors:

  • Menys codi i més llegibilitat.
  • No cal gestionar __iter__ ni __next__.
  • Estalvi de memòria, ja que els valors es generen sobre la marxa (lazy evaluation).

El Garbage Collector (GC) de Python

El Garbage Collector és el mecanisme encarregat d'administrar la memòria automàticament en Python. Elimina els objectes que ja no s’utilitzen, alliberant espai i evitant fugues de memòria.

Exemple conceptual

    
  >>> b = 3
  >>> a = 5
  >>> a = b

Quan a = 5, l’objecte 5 té una referència. Però després a = b, a passa a referenciar 3. Com ningú apunta ja a 5, queda sense ús i el GC el pot eliminar.

Funcionament intern

  • Conteig de referències: cada objecte té un comptador que indica quantes referències l’apunten. Si arriba a zero, es pot eliminar automàticament.
  • Recol·lecció de brossa generacional: els objectes s’organitzen en generacions (0, 1 i 2). Els nous comencen en la generació 0, i si “sobreviuen” diverses neteges, passen a generacions superiors.

Python fa neteges més freqüents en la generació 0 que en les superiors, perquè és més probable que els objectes nous siguen de curta duració.

Control manual amb el mòdul gc

Encara que el GC funciona automàticament, es pot controlar manualment amb el mòdul gc:

  import gc
  
  gc.collect()      # Força una execució del garbage collector
  gc.get_stats()    # Mostra estadístiques sobre el GC

Expressions regulars

Les expressions regulars (també conegudes com a regex) són patrons que permeten buscar, comprovar i manipular text seguint unes regles determinades.

Per exemple, podem utilitzar una expressió regular per comprovar si una cadena té el format d'un correu electrònic, per trobar tots els números que apareixen en un text o per substituir determinats fragments.

En Python, les expressions regulars es treballen principalment mitjançant el mòdul re.

import re

Patrons i coincidències

Una expressió regular està formada per un patró. El patró descriu què volem buscar dins d'un text.

Per exemple, el patró gat busca exactament la seqüència de caràcters gat.

import re
text = "El gat està dormint."
resultat = re.search("gat", text)
print(resultat)
<re.Match object; span=(3, 6), match='gat'></re.Match>

Si el patró es troba dins del text, re.search() retorna un objecte de tipus Match. Si no el troba, retorna None.

import re
text = "El gat està dormint."
resultat = re.search("gos", text)
print(resultat)
# None

El mètode search()

re.search() busca el patró en qualsevol posició de la cadena i retorna la primera coincidència que troba.

import re
text = "Python és un llenguatge de programació."
resultat = re.search("Python", text)
if resultat:
   print("S'ha trobat el text")
else:
   print("No s'ha trobat")

Podem obtindre el text que ha coincidit mitjançant el mètode group().

import re
text = "El meu número és 12345."
resultat = re.search(r"\d+", text)
if resultat:
   print(resultat.group())
   # 12345

La r davant de la cadena indica que estem utilitzant una raw string. És una forma habitual d'escriure patrons d'expressions regulars, especialment quan contenen la barra invertida \.

Classes de caràcters

Les expressions regulars disposen de símbols especials per representar diferents tipus de caràcters.

Patró Significat Exemple
\d Qualsevol dígit 0, 1, 2, ...
\D Qualsevol caràcter que no siga un dígit a, X, !, ...
\w Caràcter de paraula a, B, 7, _
\W Caràcter que no siga de paraula !, ?, espai...
\s Espai en blanc espai, tabulador, salt de línia...
\S Caràcter que no siga un espai en blanc a, 7, !...

Exemple amb dígits

El patró \d permet trobar un dígit. Si volem trobar un o més dígits consecutius, podem utilitzar \d+.

import re
text = "L'edat de Joan és 25 anys."
resultat = re.search(r"\d+", text)
print(resultat.group())
# 25

Quantificadors

Els quantificadors indiquen quantes vegades pot aparéixer un element del patró.

Quantificador Significat
* Zero o més vegades
+ Una o més vegades
? Zero o una vegada
{n} Exactament n vegades
{n,m} Entre n i m vegades

Exemple

El patró \d{3} busca exactament tres dígits consecutius.

import re
text = "Codi: 123"
resultat = re.search(r"\d{3}", text)
print(resultat.group())
# 123

En canvi, \d+ busca una seqüència formada per un o més dígits.

import re
text = "Productes: 12, 35 i 108"
resultats = re.findall(r"\d+", text)
print(resultats)
# ['12', '35', '108']

El mètode findall()

Quan volem trobar totes les coincidències d'un patró, podem utilitzar re.findall().

import re
text = "Els números són 12, 25 i 48."
numeros = re.findall(r"\d+", text)
print(numeros)
# ['12', '25', '48']

La diferència principal amb search() és:

  • search() busca la primera coincidència.
  • findall() retorna totes les coincidències.

Conjunts de caràcters

Amb els claudàtors [] podem indicar un conjunt de caràcters.

import re
text = "gat gos git"
resultats = re.findall(r"g[aeiou]t", text)
print(resultats)
# ['gat', 'git']

El patró [aeiou] indica que en aquesta posició pot aparéixer qualsevol de les cinc vocals.

També podem utilitzar un rang de caràcters:

[0-9]       # qualsevol dígit
[a-z]       # qualsevol lletra minúscula
[A-Z]       # qualsevol lletra majúscula

Inici i final d'una cadena

Alguns símbols permeten indicar la posició dins de la cadena.

Símbol Significat
^ Inici de la cadena
$ Final de la cadena

Per exemple, el patró següent comprova que la cadena comence per Python:

import re
text = "Python és fàcil d'aprendre."
if re.search(r"^Python", text):
   print("La cadena comença per Python")

El mètode match()

re.match() comprova la coincidència des de l'inici de la cadena.

import re
text = "Python és un llenguatge."
resultat = re.match(r"Python", text)
if resultat:
   print("Coincideix")
else:
   print("No coincideix")

Per això, match() i search() no són exactament iguals:

  • match() només comprova des del principi.
  • search() pot trobar la coincidència en qualsevol posició.

El mètode fullmatch()

Quan volem comprovar que tota la cadena compleix un patró, podem utilitzar re.fullmatch().

Per exemple, per comprovar que una cadena conté exactament quatre dígits:

import re
text = "1234"
resultat = re.fullmatch(r"\d{4}", text)
if resultat:
   print("Format correcte")
else:
   print("Format incorrecte")

A diferència de search(), no n'hi ha prou que una part de la cadena coincidisca. Ha de coincidir tota la cadena.

Substituir text amb sub()

Les expressions regulars també permeten substituir fragments de text.

import re
text = "El meu telèfon és 612345678."
nou_text = re.sub(r"\d+", "XXXXXXXXX", text)
print(nou_text)
# El meu telèfon és XXXXXXXXX.

re.sub() rep principalment tres elements:

  1. El patró que volem buscar.
  2. El text de substitució.
  3. El text original.

Grups

Els parèntesis () permeten crear grups dins d'una expressió regular.

Per exemple, podem separar el nom d'usuari i el domini d'un correu electrònic:

import re
text = "[usuari@example.com](mailto:usuari@example.com)"
resultat = re.search(r"(\w+)@(\w+.\w+)", text)
if resultat:
  print(resultat.group(1))
  print(resultat.group(2))

# usuari
# example.com

Els grups són especialment útils quan, a més de trobar una coincidència, volem extraure diferents parts de la informació.

Exemple pràctic: comprovar un DNI

Podem utilitzar una expressió regular per comprovar el format d'un DNI espanyol: huit dígits seguits d'una lletra.

import re
dni = "12345678Z"
patro = r"\d{8}[A-Za-z]"
if re.fullmatch(patro, dni):
   print("Format de DNI correcte")
else:
   print("Format de DNI incorrecte")

Important: aquesta expressió regular només comprova el format. No comprova que la lletra siga la que correspon matemàticament als huit dígits del DNI.

Expressions regulars: resum

Element Funció

\w Caràcter de paraula
\s Espai en blanc
+ Una o més vegades
* Zero o més vegades
? Zero o una vegada
{n} Exactament n vegades
[] Conjunt de caràcters
^ Inici de la cadena
$ Final de la cadena
() Grup

Una expressió regular és un patró que descriu una determinada forma de text. En Python, el mòdul re ens permet buscar, comprovar, extraure i substituir informació utilitzant aquests patrons.

Es poden fer comprovacions de patrons senzills sense re , utilitzant els mètodes normals de les cadenes.

if text.isdigit():
if text.isalpha():    
if text.isalnum():
text.startswith("http")
text.endswith(".com")
text.lower()
text.upper()
text.find("Python")

Per exemple, imagina que volem comprovar que una cadena té aquest format:

AB-1234-CD
Sense re ho podríem fer, però necessitaríem bastant codi: 
text = "AB-1234-CD"
correcte = (
    len(text) == 10 and

Format JSON

JSON (JavaScript Object Notation) és un format de text utilitzat per representar i intercanviar dades estructurades. És molt habitual en APIs, aplicacions web i fitxers de configuració.

Estructura bàsica

Un objecte JSON utilitza {} i conté parelles clau: valor. Les claus s'escriuen entre cometes dobles.

{
"nom": "Anna",
"edat": 20,
"actiu": true
}

(Açò recorda MOLT a un diccionari de Python !! ) 👀

Pot contindre arrays ...

{ 
"nom": "Anna", 
"edat":20,
"aficions": ["música", "cinema", "esport"] }

Pot contindre altres objectes (json)

{
"nom": "Anna", 
"edat": 20, 
"adreça": { "carrer": "Major", 
            "numero": 25,
            "ciutat": "València" } 
}

Pot contindre arrays d'objectes...

 { "alumnes": [ { "nom": "Anna", "edat": 20 }, { "nom": "Joan", "edat": 21 } ] }

I podem fer recursivament, combinacions de : objectes, llistes i tipus de valors

Tipus de dades

JSON Python
"Anna" str
20 int
true / false True / False
null None
{ } dict
[ ] list

JSON i Python

Python proporciona el mòdul json per convertir dades entre Python i JSON.

import json

dades = {
"nom": "Anna",
"edat": 20
}

Python → cadena JSON
text = json.dumps(dades)
cadena JSON → Python
dades2 = json.loads(text)

Treballar amb fitxers

Guardar en un fitxer

with open("dades.json", "w", encoding="utf-8") as f:
json.dump(dades, f, indent=4)

Llegir un fitxer

with open("dades.json", "r", encoding="utf-8") as f:
dades = json.load(f)

Funcions principals

Funció Conversió
json.dumps() Python → cadena JSON
json.loads() cadena JSON → Python
json.dump() Python → fitxer JSON
json.load() fitxer JSON → Python

JSON és un format de dades, no un diccionari Python. El mòdul json permet convertir entre les estructures de Python i aquest format.

Format CSV

CSV (Comma-Separated Values) és un format de text utilitzat per emmagatzemar i intercanviar dades tabulars, és a dir, dades organitzades en files i columnes.

Cada línia representa una fila i els diferents camps estan separats habitualment per comes.

Exemple

nom,edat,curs
Anna,20,DAW
Joan,21,ASIX
Maria,19,SMX

La primera fila s'utilitza habitualment com a capçalera i indica el nom de cada columna.

CSV i Python

Python proporciona el mòdul csv per treballar amb fitxers CSV.

import csv

Llegir un fitxer CSV

import csv

with open("alumnes.csv", "r", encoding="utf-8", newline="") as f:
lector = csv.DictReader(f)

for fila in lector:
    print(fila["nom"], fila["edat"])

DictReader permet accedir als camps utilitzant el nom de la columna.

Escriure un fitxer CSV

import csv

alumnes = [
["Anna", 20, "DAW"],
["Joan", 21, "ASIX"],
["Maria", 19, "SMX"]
]

with open("alumnes.csv", "w", encoding="utf-8", newline="") as f:
escriptor = csv.writer(f)

escriptor.writerow(["nom", "edat", "curs"])

escriptor.writerows(alumnes)

CSV amb diccionaris

També podem treballar directament amb diccionaris utilitzant DictWriter.

import csv

alumne = {
"nom": "Anna",
"edat": 20,
"curs": "DAW"
}

with open("alumne.csv", "w", encoding="utf-8", newline="") as f:
camps = ["nom", "edat", "curs"]

escriptor = csv.DictWriter(f, fieldnames=camps)

escriptor.writeheader()
escriptor.writerow(alumne)

El separador

Encara que CSV significa Comma-Separated Values, el separador no ha de ser necessàriament una coma. En alguns països i aplicacions s'utilitza el punt i coma (;).

nom;edat;curs
Anna;20;DAW
Joan;21;ASIX

Podem indicar el separador en Python:

lector = csv.DictReader(f, delimiter=";")

CSV vs JSON

CSV JSON
Ideal per a dades tabulars Ideal per a dades estructurades
Files i columnes Objectes i arrays
Format molt senzill Permet estructures més complexes
Molt utilitzat amb fulls de càlcul Molt utilitzat en APIs

CSV és un format de text senzill i adequat per representar dades organitzades en files i columnes. En Python, el mòdul csv permet llegir i escriure aquestes dades fàcilment.
